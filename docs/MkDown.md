## 6. Архитектурные решения (почему так?)

| Решение | Причина |
|---------|---------|
| **Controller → Service → Repository** | Разделение ответственности, легко тестировать, легко менять |
| **DTO для создания задач** | Безопасность — клиент не может прислать лишние поля (id, userId) |
| **BCrypt для паролей** | Пароли хранятся в зашифрованном виде |
| **Spring Security + сессии** | Простота для учебного проекта, не нужны JWT токены |
| **PostgreSQL** | Надёжная реляционная БД, есть внешние ключи и транзакции |
| **Thymeleaf + чистый JS** | Минимальный фронтенд без лишних фреймворков |
